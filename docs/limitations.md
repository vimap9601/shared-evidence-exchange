# Limitations

- Model agreement does not prove correctness.
- Two models may share the same blind spots.
- Cloud connectors may have partial search, parsing, or write capabilities.
- Drawings, images, and tables may require visual review.
- Scheduled tasks may not run at exact intervals.
- A watcher on one platform does not automatically activate another platform.
- Context snapshots may preserve previous errors.
- Automated brokers can incur substantial API costs.
- Human review remains necessary for consequential decisions.
