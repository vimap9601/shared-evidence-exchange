# Design Principles

## Evidence before eloquence

A polished answer is not a substitute for a primary source.

## Externalized context

Important project state belongs in files, not solely in chat history.

## Append-only history

Corrections should be visible. Silent edits destroy auditability.

## Productive disagreement

The workflow should reward locating unsupported assumptions, not rapid consensus.

## Revisability

A model changing its position after receiving stronger evidence is a success.

## Portable references

Evidence references must survive movement between providers.

## Human authority

Models organize and test evidence. Humans decide and authorize consequential actions.
