# GitHub Upload Checklist

- [ ] Extract the ZIP before uploading.
- [ ] Upload the contents of `shared-evidence-exchange`, not a second nested ZIP.
- [ ] Replace `Ctrl-Alt-Karma` in `README.md` and `pyproject.toml`.
- [ ] Confirm the project name and description.
- [ ] Confirm the MIT copyright line names the intended owner.
- [ ] Verify no private project evidence or credentials are present.
- [ ] Commit all folders, including `.github`.
- [ ] Open the Actions tab and confirm CI passes.
- [ ] Enable private vulnerability reporting.
- [ ] Add repository topics such as `ai`, `multi-agent`, `peer-review`, and `audit`.
- [ ] Create a `v0.1.0` release and attach the ZIP if desired.
