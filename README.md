## 🛠 Features

The software includes several tools to help your workflow:

*   **Evidence Tracking:** Link specific documents to your AI model findings. It maps every claim to a source.
*   **Peer Review Logs:** Maintain a history of who reviewed each finding and when they approved it.

## 📋 How to Use the Application

Once you install the program, opening it reveals the main dashboard. 

### Setting Up Your Workspace
You first define where your evidence lives. If you store data in Google Drive, select the "Connect Data" option. Provide your credentials when the system asks. This allows the application to pull files safely. 

### Starting a Review
Select "New Review" from the top menu. Enter a name for the current project. You will see a workspace consisting of three columns:
1. **Evidence Ingestion:** This column holds your raw data, such as PDFs or text files.
2. **Review Notes:** Use this space to write comments about the model performance.
3. **Verification Gate:** This is where the magic happens. Here, you define the criteria that a claim must pass before the system marks it as complete.

### Processing Claims
When an AI model produces a finding, attach the relevant evidence document to it. The system automatically creates a trail that links the claim to the source. If the tool finds a mismatch, it flags the item. You must review these flags manually. This process ensures human oversight remains part of your workflow.
